# Contributing

Fork the repo and open a pull request with a short explanation and screenshots or a preview link.

Use the local preview command in README.md. Check mobile and desktop layouts, keyboard navigation, reduced motion, script copying, and the clipboard fallback.

Keep the script and Discord links working. Only include assets you have permission to contribute and retain their required attribution. Keep credentials and backend code out of this repo.

The owner reviews and deploys accepted changes. No server access is needed to work on the frontend.
